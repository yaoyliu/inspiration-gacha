# 灵感抽卡器

一个在本机运行的小工具：从词库里随机抽标签，组合成角色或世界的设定素材，复制给云端大模型扩写成完整内容。不用安装、不用联网、不用账号。

## 目录里有什么

```
inspiration-gacha\
├── index.html        工具本体，双击用浏览器打开
├── README.md         本说明
├── tutorial.png      一图流教程，一张图看懂全部用法
└── wordbanks\        词库文件夹，整个文件夹可以直接发给别人
    ├── index.js      选项卡清单 + 角色基础设定
    ├── avatar.js     头像词库
    ├── art.js        立绘词库
    ├── persona.js    人设词库
    └── world.js      世界观词库
```

`index.html` 和 `wordbanks` 放在同一层。`index.html` 里也存了一份词库，所以只带这一个 HTML 文件同样能用，只是改 `wordbanks` 里的文件不会影响它。

## 开始用

1. 双击 `index.html`。
2. 顶部选项卡列出四份词库，点哪根就抽哪份；右侧是抽到的标签和可复制的文本。
3. 每个维度用滑块决定抽几个，拖动就更新；点「重新生成」重抽一次。
4. 「复制组合」只复制标签文本，「复制完整提示词」会在前面加一段给大模型的引导语。
5. 结果区可以切换中文 / English，并决定是否带维度前缀。

当前选项卡、滑块数值、固定值、锁定、语言、基础设定、词库改动都自动存在浏览器里，下次打开还在。

## 选项卡

选项卡栏右侧有「＋ 新建」和「打开词库文件」，每根选项卡上有 ×，分类头有「重命名」。

| 操作 | 说明 |
| --- | --- |
| ＋ 新建 | 填名称、选输出形式，建一份自己的空词库；勾「以当前词库为模板」可先复制现有维度 |
| 打开词库文件 | 可一次多选几个 `.js` / `.json`，每份成为一根选项卡 |
| × 关闭 | 移走这根选项卡，词库文件不会删除，之后用「打开词库文件」还能载入；至少留一根 |
| 重命名 | 改显示名 |
| 加入基础设定 | 开关；打开后把角色基础设定一起放进这组结果 |
| 扩写成… | 选「绘图提示词」或「文字设定」，决定完整提示词让模型交什么 |

新建、打开、关闭、改名、改输出形式后，点「保存到文件夹」写进 `index.js`，刷新后就固定下来。在网页里编辑过词库同样会显示「● 有未保存到文件夹的改动」，保存前改动一直留在浏览器里。

## 滑块

| 数值 | 含义 |
| --- | --- |
| `-1` | 固定：用下拉框选中的那个值，不随机 |
| `0` | 跳过这个维度 |
| `1 ~ 10` | 随机抽几个不重复的标签，默认 1，最多 10 |

词条不足 10 条时，上限就是它的实际条数。抽到多个值用 ` / ` 连起来。分类头的「批量设置」可以一次把整份词库设成固定、跳过或抽 1/2/3/5/10 个。

## 基础设定

左侧「基础设定」面板是角色共用的 4 项信息：性别、年龄、身高、体重。名称、值都能改，可以 `×` 删除，「+ 新增设定」加字段，「恢复默认设定」回到这 4 项。值写成 `中文|English` 时会跟着输出语言变化。

在选项卡头部打开「加入基础设定」，这些设定就排在这一组标签最前，也写进输出文本，例如 `女、18 岁、165 cm、48 kg、正面特写、…`，组标题会显示「+基础设定」。世界观是场景设定，默认不带人物信息。

## 输出语言与维度前缀

结果区顶部可切换 **中文** 和 **English**，只改变显示和复制的文字，不重新抽卡：

- 中文：`【头像 Tag】` 下一行 `女、18 岁、正面特写`
- English：`[Avatar Tags]` 下一行 `Female, 18 years old, Frontal close-up`

内置词库 1797 个词条都带英文；分类名和维度名也有英文对照。自己写的词条如果只有一段文字，两种语言下都显示这段文字。

**「维度前缀」** 默认不勾：输出只给词条本身。勾上后每个值前面加维度名：

- 不勾：`女、18 岁、165 cm、正面特写、淡淡微笑`
- 勾上：`性别: 女、年龄: 18 岁、身高: 165 cm、构图视角: 正面特写、表情神态: 淡淡微笑`

English 模式下维度名也是英文，例如 `Gender: Female`。切换开关不重新抽卡，历史组合保留生成时的格式。

## 词条怎么写

词库里每个候选项是一行文字，推荐写成 `中文|English`，这样中文模式显示前半、English 模式显示后半：

```json
"表情神态": ["淡淡微笑|Faint smile", "面无表情|Blank expression"]
```

写成别的样子也能用，词条不会丢：

| 写法 | 中文模式 | English 模式 |
| --- | --- | --- |
| `淡淡微笑` | 淡淡微笑 | 淡淡微笑 |
| `淡淡微笑\|Faint smile` | 淡淡微笑 | Faint smile |
| `\|Faint smile` | Faint smile | Faint smile |
| `淡淡微笑\|` | 淡淡微笑 | 淡淡微笑 |
| `甲\|Alpha\|Beta` | 甲 | Alpha \| Beta |
| `\|` （只有分隔符） | — | — |

也就是说，词条随便写都能在两种语言里看到，不会因为格式不对变成空白或消失。

## 复制完整提示词

「复制完整提示词」在结果文本前加一段引导语，内容随当前选项卡的「扩写成…」变化：

| 输出形式 | 用于 | 引导语要求 |
| --- | --- | --- |
| 绘图提示词（`image`） | 头像、立绘 | 只输出一段可直接用于绘图模型的描述性短语，写外貌、表情、姿态、构图、光线、画风；不写人物小传、剧情或世界观 |
| 文字设定（`text`） | 人设、世界观、自建词库 | 只输出连贯的设定正文；不输出绘图提示词、标签串或绘画指令 |

两种引导语都要求模型：同一维度抽到多个标签时先自洽解释再全部保留、不改动或删减标签、没出现的维度不凭空补写、命名前后一致。组里有基础设定时会额外要求人物信息全程一致；维度前缀的状态也会写进去，让模型知道标签是「维度: 值」还是纯词条。语言切到 English，引导语也换成英文。

输出形式属于选项卡，在分类头下拉里改，新建时就能选，保存后写进 `index.js` 的 `kind`。

## 锁定

每个随机标签右侧有个小圆点，点一下锁定这个值。之后点「重新生成」，锁定的值保留，再从剩下的词条里补足抽取个数。「清空锁定」一次解除全部。固定（`-1`）和基础设定不用锁定。

## 词库文件

**`wordbanks/index.js`** 存选项卡清单和基础设定：

```js
window.TAG_TABS = [
  { "id": "avatar", "name": "头像",   "file": "avatar.js",  "color": "#7c6cf5", "baseOn": true,  "kind": "image" },
  { "id": "art",    "name": "立绘",   "file": "art.js",     "color": "#3d8ce0", "baseOn": true,  "kind": "image" },
  { "id": "persona","name": "人设",   "file": "persona.js", "color": "#e08a3c", "baseOn": true,  "kind": "text"  },
  { "id": "world",  "name": "世界观", "file": "world.js",   "color": "#2fa88f", "baseOn": false, "kind": "text"  }
];
window.TAG_PROFILE = [
  { "name": "性别", "value": "女|Female" },
  { "name": "年龄", "value": "18 岁|18 years old" },
  { "name": "身高", "value": "165 cm|165 cm" },
  { "name": "体重", "value": "48 kg|48 kg" }
];
```

`id` 不能重复，`file` 是同文件夹里的词库文件名，`color` 是选项卡的小圆点颜色，`baseOn` 是「加入基础设定」的初始值，`kind` 是输出形式（`image` 绘图提示词 / `text` 文字设定；不写时头像、立绘按 `image`，其余按 `text`）。把一份词库文件放进文件夹、在 `TAG_TABS` 里加一行，刷新网页就会多一根选项卡。

**单份词库**（例如 `avatar.js`）：

```js
window.TAG_BANK = window.TAG_BANK || new Object();
window.TAG_BANK["avatar"] = {
  "label": "头像",
  "fields": {
    "表情神态": ["淡淡微笑|Faint smile", "面无表情|Blank expression"],
    "发型": ["长直发|Long straight hair", "双马尾|Twin tails"]
  }
};
```

`label` 是显示名，`fields` 里每个维度名对应一组候选项。文件必须是合法 JSON：英文双引号、逗号分隔、最后一项后不加逗号。用记事本或 VS Code 改完保存，刷新网页生效。

## 保存到文件夹

点「词库与文件夹 → 保存到文件夹」，会把 `index.js` 和所有选项卡的词库文件一起写回。

- **Chrome / Edge**：弹出目录选择框，选一次 `wordbanks` 就写入全部文件；同一会话里再保存会沿用这个文件夹。保存成功后标记变成「✓ 已与文件夹同步」。
- **其他浏览器**：逐个下载这些文件，放进 `wordbanks` 覆盖同名文件即可。还没覆盖时工具继续用浏览器里的编辑，改动不会丢。

面板里还有：「另存当前词库」下载一份词库副本、「复制当前词库文本」取单份 JSON、「导入到当前选项卡」把粘贴的文本覆盖到当前词库、「重新读取文件夹」重新加载文件、「恢复内置选项卡」按 `index.js` 重建清单。

**以哪份为准**：没在网页里改过时，`wordbanks` 里的文件说了算（改文件刷新就生效，滑块设置保留）；在网页里改过后以浏览器里的编辑为准；保存到文件夹成功后重新以文件为准。关掉的内置选项卡刷新后不会自己回来，除非在 `index.js` 里删掉它，或点「恢复内置选项卡」。

分享时把整个 `wordbanks` 文件夹发过去放进同一目录，词库、清单、基础设定就一起带过去了；只发一两个 `.js` 也行，对方用「打开词库文件」载入。

## 常见问题

**改了词库文件，刷新没变化？**
看「词库与文件夹」里的来源和同步标记。显示「网页内编辑（未保存）」就先点「保存到文件夹」或「重新读取文件夹」。也确认文件确实在 `wordbanks` 里、`index.js` 的 `file` 和文件名一致、JSON 没写错。

**新建的选项卡刷新后不见了？**
新建、打开、关闭后点一次「保存到文件夹」写进 `index.js`。没保存时改动还在浏览器里，同一个浏览器刷新会保留，换浏览器或清缓存就带不过去。

**抽出来的标签太多？**
用分类头的「批量设置 → 全部跳过 0」，再把要的几个维度单独调成 1；也可以关掉「加入基础设定」或「维度前缀」。

**设置存在哪？**
浏览器本地存储。顶部「恢复默认」可以清空重来；换浏览器不会同步，用「保存到文件夹」备份整个词库文件夹。

## 内置规模

- 词库：4 根选项卡 / 86 个维度 / 1797 个候选项（头像 20 维、立绘 20 维、人设 23 维、世界观 23 维），全部带英文对照。
- 基础设定：4 项，都能自定义。
