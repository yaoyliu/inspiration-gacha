# 灵感抽卡器

一个在本机运行的小工具：从词库里随机抽标签，组合成角色或世界的设定素材，复制给云端大模型扩写成完整内容。不用安装、不用联网、不用账号。

## 目录里有什么

```
inspiration-gacha\
├── index.html        工具本体，双击用浏览器打开
├── README.md         本说明
├── conflicts.js      组合校验规则
├── tutorial.png      一图流教程，一张图看懂全部用法
└── wordbanks\        词库文件夹
    ├── index.js      选项卡清单 + 角色基础设定
    ├── avatar.js     头像词库
    ├── art.js        立绘词库
    ├── persona.js    人设词库
    └── world.js      世界观词库
```

`index.html`、`conflicts.js` 和 `wordbanks` 放在同一层，三者要在一起才能用。把整个文件夹发给别人，工具、词库、清单和规则就一起带过去了。

## 开始用

1. 双击 `index.html`。
2. 顶部选项卡列出四份词库，点哪根就抽哪份；右侧是抽到的标签和可复制的文本。
3. 每个维度用滑块决定抽几个，拖动就更新；点「重新生成」重抽一次，点维度行右侧的重抽小按钮只换这一个维度。
4. 「复制组合」只复制标签文本，「复制完整提示词」会在前面加一段给大模型的引导语。
5. 结果区可以切换中文 / English；维度前缀、组合校验、生图模型与自定义冲突词组在右上角「设置」里调整。

当前选项卡、滑块数值、固定值、锁定、语言、基础设定、词库改动都自动存在浏览器里，下次打开还在。

## 选项卡

选项卡栏右侧有「＋ 新建」和「打开词库文件」，每根选项卡上有 ×，分类头有「重命名」。

| 操作 | 说明 |
| --- | --- |
| ＋ 新建 | 填名称、选输出形式，建一份自己的空词库；勾「以当前词库为模板」可先复制现有维度 |
| 打开词库文件 | 可一次多选几个 `.js` / `.json`，每份成为一根选项卡 |
| × 关闭 | 移走这根选项卡，词库文件不会删除，之后用「打开词库文件」还能载入；至少留一根 |
| 重命名 | 改显示名 |
| 加入基础设定 | 分类头的开关；打开后把角色基础设定一起放进这组结果 |
| 扩写成… | 分类头的下拉；选「绘图提示词」或「文字设定」，决定完整提示词让模型交什么 |

新建、打开、关闭、改名、改输出形式、编辑词库，都会立刻存在浏览器里，刷新后还在。要把这些改动写进 `index.js` 和词库文件，点「导出词库文件」，再用下载到的 `wordbanks.zip` 覆盖项目里的 `wordbanks`。

## 滑块

| 数值 | 含义 |
| --- | --- |
| `-1` | 固定：用下拉框选中的那个值，不随机 |
| `0` | 跳过这个维度 |
| `1 ~ 10` | 随机抽几个不重复的标签，默认 1，最多 10 |

词条不足 10 条时，上限就是它的实际条数。抽到多个值用 ` / ` 连起来。维度之间在输出文本里用逗号隔开。分类头的「批量设置」可以一次把整份词库设成固定、跳过或抽 1/2/3/5/10 个。

每个维度行下方有一行「本轮」，直接显示这个维度刚刚抽到的值；点右侧的重抽小按钮（环形箭头）只重新抽这一个维度，其他维度保持不变，锁定值照样保留。滑块在 `-1`（固定）或 `0`（跳过）时按钮隐藏。

抽到的标签都会出现在结果区、文本输出、复制组合和完整提示词里。想让某个维度不参与，把它的滑块拉到 `0`。

## 基础设定

左侧「基础设定」面板写一段角色共用的设定，内容自己定，例如 `女，18 岁，165 cm，48 kg`，也可以写更长的背景。写成 `中文|English` 时会跟着输出语言切换，只写一种语言也可以。「恢复默认设定」会填回示例里的那段话。

在选项卡头部打开「加入基础设定」，这段话就作为一条结果排在这一组标签最前，也写进输出文本，组标题会显示「+基础设定」。世界观是场景设定，默认不带人物信息。

## 风格锚点

左侧「风格锚点」卡片统一控制整套标签的风格。词库里带风格前缀的词条，例如 `古风|Classical·汉服|Hanfu`，只有选中对应风格时才参与抽取；没有前缀的词条是通用词条，任何风格都能抽到。风格列表从词库前缀自动收集，当前有古风、童话、现代、赛博朋克、西幻、和风六种。往词库里写新风格前缀，列表里就会多一个选项。

| 用法 | 说明 |
| --- | --- |
| 不选（不限） | 全部词条都参与抽取 |
| 手动勾选 | 候选池变成「通用 + 勾选的风格」，可以多选 |
| 参与抽卡 | 勾上后每次点「重新生成」自动抽几个风格，抽到的风格只作用于这一轮；旁边的滑块决定抽几个（1 ~ 6） |

多选不做硬性禁止：同时勾古风和现代，就可能抽到穿汉服又带手机的组合，交给大模型按你选的风格去协调。勾选状态和「参与抽卡」的滑块数值都存在浏览器里。本轮风格会显示在结果区，也写进文本输出和完整提示词的开头，让大模型把通用词条补成符合该风格的具体样式。

## 输出语言与维度前缀

结果区顶部可切换 **中文** 和 **English**，只改变显示和复制的文字，不重新抽卡：

- 中文：`【头像 Tag】` 下一行 `基础设定: 女，18 岁, 构图视角: 正面特写, 表情神态: 淡淡微笑`
- English：`[Avatar Tags]` 下一行 `Base: Female, 18, Composition: Frontal close-up, Expression: Faint smile`

内置词库 2473 个词条都带英文；分类名和维度名也有英文对照。自己写的词条如果只有一段文字，两种语言下都显示这段文字。

**「维度前缀」** 在「设置」里，默认勾上：每个值前面带维度名。去掉勾后输出只给词条本身：

- 勾上：`构图视角: 正面特写, 表情神态: 淡淡微笑, 发色: 亚麻金`
- 不勾：`正面特写, 淡淡微笑, 亚麻金`

English 模式下维度名也是英文，例如 `Composition: Frontal close-up`。切换开关不重新抽卡，历史组合保留生成时的格式。

「文本输出」框和每个维度的「编辑词库」框右上角都有一个斜向双箭头小按钮，点开后在占大半屏的窗口里编辑，改完点「应用」写回原处。自定义冲突词组、粘贴词库文本和新建维度时填候选项，也都能这样放大。

## 词条怎么写

词库里每个候选项是一行文字，推荐写成 `中文|English`，这样中文模式显示前半、English 模式显示后半：

```json
"表情神态": ["淡淡微笑|Faint smile", "面无表情|Blank expression"]
```

写成别的样子也能用，词条不会丢：

| 写法 | 中文模式 | English 模式 |
| --- | --- | --- |
| `淡淡微笑` | 淡淡微笑 | 淡淡微笑 |
| `淡淡微笑\|Faint smile` | 淡淡微笑 | Faint smile |
| `\|Faint smile` | Faint smile | Faint smile |
| `淡淡微笑\|` | 淡淡微笑 | 淡淡微笑 |
| `甲\|Alpha\|Beta` | 甲 | Alpha \| Beta |
| `\|` （只有分隔符） | — | — |

也就是说，词条随便写都能在两种语言里看到，不会因为格式不对变成空白或消失。

## 一次抽多组

结果区上方的「生成范围」下拉里勾选多根选项卡，点「重新生成」就能一次抽好几组。每组单独显示、单独复制，文本输出和「复制完整提示词」会包含所有勾选的组，并说明这些组属于同一个对象。默认是「跟随当前选项卡」，只抽当前这一组；下拉里也能一键全选或只留当前组。仍然只有一个「重新生成」按钮。

## 组合校验

默认开启。抽完标签后，会避开明显互斥的说法（例如长发与短发、无袖与长袖、盛夏与寒冬、俯视与仰视），并尽量从同一维度补上别的候选项，让组合读起来更自洽。只在不同维度之间比较，同一个维度抽到多个标签仍然全部保留；锁定过的值优先保留。结果区会显示本次避开了几处冲突、补了几项。「复制完整提示词」的引导语跟着开关走：开启时说明已避开互斥描述，关闭时说明需要模型自己先调和冲突。

引导语把标签当作创作素材：同一维度抽到多个标签时先视作同时成立再按整体效果取舍，允许改写、替换或舍弃不和谐的搭配，按需增删合适的设定。

规则写在 **`conflicts.js`**，一行一组，左右两边用竖线 `|` 分开，同一边的多个说法用逗号分开：

```js
window.TAG_CONFLICTS = [
  "长发,long hair | 短发,short hair,bob cut,精灵短发",
  "盛夏,酷暑,midsummer | 寒冬,严冬,deep winter"
];
```

中文和英文说法可以并列，匹配时不区分大小写，只要词里包含就会命中。想加规则就照格式加一行，不想用某条就删掉那一行。设置里的「自定义冲突词组」按同样的格式写，两处会一起生效，适合临时补几条不想写进文件的规则；设置里也能直接关掉校验。

## 复制完整提示词

「复制完整提示词」在结果文本前加一段引导语，内容随分类头的「扩写成…」变化：

| 输出形式 | 用于 | 引导语要求 |
| --- | --- | --- |
| 绘图提示词（`image`） | 头像、立绘 | 只输出一段可直接用于绘图模型的描述性短语，写外貌、表情、姿态、构图、光线、画风；不写人物小传、剧情或世界观 |
| 文字设定（`text`） | 人设、世界观、自建词库 | 只输出连贯的设定正文；不输出绘图提示词、标签串或绘画指令 |

一次抽多组、又同时有绘图组和文字组时，引导语会要求模型把两种结果分开输出。两种引导语都把标签当作创作素材：可自行改写、替换或舍弃不和谐的搭配，按需增删合适的设定，不必逐条保留原词；没提到的维度可补充细节，但不要生造专有名词，自己起的名字前后一致。组里有基础设定时要求尽量保持一致，与标签冲突时按整体效果做最小调整；维度前缀的状态也会写进去，让模型知道标签是「维度: 值」还是纯词条。语言切到 English，引导语也换成英文。

在「设置」里填 **「我的生图模型」**（例如 `Midjourney v6`、`Stable Diffusion XL`、`FLUX.1`），绘图部分的引导语就会要求模型按这个模型擅长的写法整理提示词，采用它习惯的语法、参数或权重，把标签改写成更容易出好图的描述。留空就写通用写法；只有文字组时不出现这句。这里只填模型名字，工具不会联网。

输出形式属于选项卡，在分类头改，新建时就能选，保存后写进 `index.js` 的 `kind`。

## 锁定

每个随机标签右侧有个小圆点，点一下锁定这个值。之后点「重新生成」，锁定的值保留，再从剩下的词条里补足抽取个数。结果区的「清空锁定」一次解除全部。固定（`-1`）和基础设定不用锁定。

## 词库文件

**`wordbanks/index.js`** 存选项卡清单和基础设定：

```js
window.TAG_TABS = [
  { "id": "avatar", "name": "头像",   "file": "avatar.js",  "color": "#7c6cf5", "baseOn": true,  "kind": "image" },
  { "id": "art",    "name": "立绘",   "file": "art.js",     "color": "#3d8ce0", "baseOn": true,  "kind": "image" },
  { "id": "persona","name": "人设",   "file": "persona.js", "color": "#e08a3c", "baseOn": true,  "kind": "text"  },
  { "id": "world",  "name": "世界观", "file": "world.js",   "color": "#2fa88f", "baseOn": false, "kind": "text"  }
];
window.TAG_PROFILE = "女，18 岁，165 cm，48 kg|Female, 18, 165 cm, 48 kg";
```

`id` 不能重复，`file` 是同文件夹里的词库文件名，`color` 是选项卡的小圆点颜色，`baseOn` 是「加入基础设定」的初始值，`kind` 是输出形式（`image` 绘图提示词 / `text` 文字设定；不写时头像、立绘按 `image`，其余按 `text`）。把一份词库文件放进文件夹、在 `TAG_TABS` 里加一行，刷新网页就会多一根选项卡。

**单份词库**（例如 `avatar.js`）：

```js
window.TAG_BANK = window.TAG_BANK || new Object();
window.TAG_BANK["avatar"] = {
  "label": "头像",
  "fields": {
    "表情神态": ["淡淡微笑|Faint smile", "面无表情|Blank expression"],
    "发型": ["长直发|Long straight hair", "双马尾|Twin tails"]
  }
};
```

`label` 是显示名，`fields` 里每个维度名对应一组候选项，写成字符串数组即可。文件必须是合法 JSON：英文双引号、逗号分隔，最后一项后不加逗号。用记事本或 VS Code 改完保存，再到「词库与文件夹」点「导入词库文件」选中改过的文件，网页才会用上新内容。

## 导出与导入词库

网页里的修改一直存在浏览器里，刷新不会丢；「● 词库有改动」只是提醒还没导出文件。

**导出词库文件**：在「词库与文件夹」点一下，浏览器下载一个 `wordbanks.zip`，里面是 `index.js` 和每根选项卡的词库文件。不用选文件夹，点一下就好。

- 想更新项目里的词库：解压 zip，把里面的 `.js` 放进项目的 `wordbanks` 覆盖同名文件。
- 想分享：直接把这个 zip 发给别人，对方用「导入词库文件」选中它即可。
- `conflicts.js` 用记事本直接改，不在这个压缩包里。

**导入词库文件**：点一下打开文件选择框，选刚下载的 `wordbanks.zip` 就行；也可以一次多选 `index.js` 和各词库 `.js` 文件（用记事本改过文件时这么做）。选中后网页立刻换成文件里的内容，并提示导入了几根选项卡、几个维度。只选一份 `.json` 备份时，会覆盖当前选项卡的词库。

面板里还有：「另存当前词库」导出当前这一份的 `.json` 备份、「复制当前词库文本」取单份 JSON、「导入到当前选项卡」把粘贴的文本覆盖到当前词库、「恢复内置选项卡」按项目 `wordbanks` 里的文件重建选项卡。选项卡栏的「打开词库文件」是把选中的每份文件加成新选项卡。

**以哪份为准**：网页里保存的词库说了算。改了 `wordbanks` 里的文件，要用「导入词库文件」才会进到网页；网页里改了词库，要用「导出词库文件」才会变成文件。滑块数值、固定值、锁定、语言和设置里的通用选项一直存在浏览器里，不受导入导出影响。换浏览器或清缓存前，记得导出一份 zip。

分享时把整个项目文件夹发过去即可；只发 `wordbanks.zip` 也行，对方导入就能用。

## 常见问题

**改了词库文件，网页里没变化？**
改完要点「导入词库文件」选中改过的文件（或选 `wordbanks.zip`），网页才会换成文件里的内容。也确认文件确实在 `wordbanks` 里、`index.js` 的 `file` 和文件名一致、JSON 没写错。

**新建的选项卡刷新后不见了？**
新建、打开、关闭都立刻存在浏览器里，同一个浏览器刷新会保留。换浏览器或清缓存会丢，先点「导出词库文件」存一份 zip。

**抽出来的标签太多？**
用分类头的「批量设置 → 全部跳过 0」，再把要的几个维度单独调成 1；也可以关掉「加入基础设定」或「维度前缀」。

**设置存在哪？**
浏览器本地存储。顶部「恢复默认」可以清空重来，设置里的通用选项会保留；换浏览器不会同步，用「导出词库文件」存一份 zip 带到另一台电脑。

- 风格：古风、童话、现代、赛博朋克、西幻、和风六种，共 648 条带前缀词条。
- 基础设定：一整段话，内容自己定。
- 组合校验：`conflicts.js` 里 13 组常见互斥说法，设置里可以再补。
